# isposch

HTTP-сервер, который забирает расписание занятий в формате XML, оставляет занятия одной группы и отдаёт их как календарь iCalendar (`.ics`). Календарь можно подключить по ссылке в Google Calendar, Apple Calendar, Outlook и т. д.

```
client → server → parser → ical → server → client
```

## Возможности

- Загрузка расписания по HTTP (таймаут, проверка статуса, лимит размера ответа)
- Фильтрация по группе
- Экранирование спецсимволов и перенос длинных строк

## Требования

- Проверялось на Go 1.27.1, но должно работать и на более ранних версиях. Пишите в issue если не работает.

## Запуск

```
go run . -source "<URL с XML-расписанием>"
```

Или сборка в бинарник:

```
go build -o isposch.exe .
isposch.exe -source "<URL с XML-расписанием>"
```
### Я знаю, что в политехе расписание доступно две недели, и они зачем-то сделали так, что каждое новое расписание = новый xml файл, но я не хочу этим заниматься сейчас, поэтому решу эту проблему позже. Пока что сервер просто берёт XML по указанному URL и отдаёт его как календарь.

### Флаги

| Флаг | По умолчанию | Описание |
|---|---|---|
| `-source` | нет (обязателен) | URL с XML-расписанием |
| `-addr` | `:8080` | адрес, на котором слушает сервер |
| `-tz` | `Europe/Moscow` | часовой пояс занятий |

## Использование

```
GET /schedule.ics?group=<номер группы>
```

Чтобы подписаться в календаре («Другие календари» → «Из URL»), сервер должен быть доступен из интернета: `localhost` не подойдёт.

### Коды ответов

| Код | Когда |
|---|---|
| 200 | календарь собран (для неизвестной группы он будет пустым) |
| 400 | не указан параметр `group` |
| 405 | метод не `GET` и не `HEAD` |
| 502 | источник расписания недоступен или вернул некорректный XML |
| 500 | ошибка сборки календаря |

## Формат входных данных

Ожидается XML такого вида:

```xml
<dataroot>
	<My>
		<ID>1</ID>
		<DAT>2026-09-10T00:00:00</DAT>
		<UR>1</UR>
		<FAMIO>Иванов И.И.</FAMIO>
		<SPPRED.NAIM>Предмет</SPPRED.NAIM>
		<SPGRUP.NAIM>1234</SPGRUP.NAIM>
		<AUD>101</AUD>
		<NOTE/>
		<CAMPUS>Э</CAMPUS>
	</My>
</dataroot>
```

Поля: `ID` (используется для стабильного `UID`), `DAT` (дата), `UR` (номер пары), `FAMIO` (преподаватель), `SPPRED.NAIM` (предмет), `SPGRUP.NAIM` (группа), `AUD` (аудитория), `NOTE` (примечание), `CAMPUS` (корпус).

## Время пар

Время начала задаётся таблицей `bells` в `ical/ical.go`:

| Пара | Начало |
|---|---|
| 1 | 09:00 |
| 2 | 10:45 |
| 3 | 12:50 |
| 4 | 14:30 |
| 5 | 16:10 |

Длительность пары 90 минут (`lessonDuration`). Если в данных встретится номер пары вне таблицы, календарь не соберётся и сервер вернёт 500.

## Структура проекта

```
isposch/
├── go.mod
├── main.go           # флаги и запуск сервера
├── parser/           # XML -> []Lesson, фильтрация
├── ical/             # []Lesson -> текст календаря
└── server/           # HTTP-обработчик
```

Зависимости идут в одну сторону: `server` → `ical` → `parser`.

## Тесты

## Известные ограничения

- Нет кеша: XML скачивается при каждом запросе.
- Поддерживается только UTF-8.
- Значения полей `ZAM` и `KONS` читаются, но пока нигде не используются.
